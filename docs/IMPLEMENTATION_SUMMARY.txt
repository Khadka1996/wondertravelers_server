🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. Start Backend:
   $ cd server && npm start

2. Start Frontend:
   $ cd client && npm run dev

3. Access Admin Panel:
   http://localhost:3000/admin/featured-images

4. Create Featured Image:
   • Click "Add Image"
   • Fill title, image URL, details
   • Click "Create"
   • Toggle green status to activate
   • Image appears on homepage!

5. View Analytics:
   http://localhost:3000/admin/analytics


🔗 ADMIN PANEL ROUTES
═══════════════════════════════════════════════════════════════════════════════

Public Website:
  http://localhost:3000              → Homepage with hero section

Admin Panel:
  http://localhost:3000/admin        → Dashboard
  http://localhost:3000/admin/featured-images → Image CRUD ⭐
  http://localhost:3000/admin/analytics      → Analytics
  http://localhost:3000/admin/settings       → Settings
  http://localhost:3000/admin/users          → Users (planned)

API Endpoints:
  GET  /api/featured-images/public?limit=4        → Get 4 active
  POST /api/featured-images/public/:id/view       → Track view
  POST /api/featured-images/public/:id/click      → Track click
  GET  /api/featured-images                       → Admin: Get all
  POST /api/featured-images                       → Admin: Create
  PUT  /api/featured-images/:id                   → Admin: Update
  DELETE /api/featured-images/:id                 → Admin: Delete
  POST /api/featured-images/reorder               → Admin: Reorder
